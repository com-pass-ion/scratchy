#+TITLE: Emacs GDB Setup - Built-in Only (gud/gdb-mi)
#+AUTHOR: distilled from debug_cpp
#+PROPERTY: header-args:sh :results silent

* Overview

Project-agnostic GDB defaults (owned by init.el) + builtin =gud/gdb-mi=.

GDB integration with zero external Emacs packages (MELPA). Works on
Linux aarch64/x86_64 for forward debugging. Reverse debugging via =record=
is best-effort; =rr= is x86_64 only. One entry point (=M-x my/cpp-debug=),
built-in GDB abbreviations, values/arrays printed by default, no custom
keys, no completions in GDB buffers.

** Files

| File                     | Purpose                              |
|--------------------------+--------------------------------------|
| =init.el= Sec.21 block   | All GDB config (defaults, entry point) |
| =M-x my/cpp-debug=       | Build (Debug) + launch GDB on any project |

* 1. Build - Debug Symbols

** CMake (project-level)

=CMakeLists.txt:8-14= conditional Debug build:

#+BEGIN_SRC cmake
if(NOT CMAKE_BUILD_TYPE)
    set(CMAKE_BUILD_TYPE Debug)
endif()

if(CMAKE_BUILD_TYPE STREQUAL "Debug")
    set(CMAKE_CXX_FLAGS "${CMAKE_CXX_FLAGS} -g -O0 -fno-inline")
endif()
#+END_SRC

** Compile command

=M-x compile= runs (explicit Debug type; delete =build/= if switching from Release cache):

#+BEGIN_SRC sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug && cmake --build build
#+END_SRC

* 2. .gdbinit (General / Project-Agnostic)

#+BEGIN_SRC gdb
# Pretty-printing
set print pretty on
set print array on
set print array-indexes on
set print elements 0
set print object on
set print address off
set print symbol-file on

# Usability
set pagination off
set breakpoint pending on

# Disable confirmations
set confirm off
#+END_SRC

Note: =debug-file-directory= is intentionally left at its default
(= /usr/lib/debug=) so system symbols still resolve. Do not set it to =.=.
The old =define hook-quit / bt / end= auto-backtrace is omitted: it errors
when no inferior is running.
These sets are owned by =my/gdb-init-args= in init.el (§7) and passed as
=-ex= flags — no .gdbinit file needed.

* 3. Auto-Deref Pointers

Example target types (from =debug_cpp= demo, not general):

| Variable              | Type                      | Location                    |
|-----------------------+---------------------------+-----------------------------|
| =res=                 | =unique_ptr<Resource>=     | =src/main.cpp:100=          |
| =res2=                | =shared_ptr<Resource>=     | =src/main.cpp:106=          |
| =ref_count_=          | =shared_ptr<int>=          | =subproject/utils.cpp:55=   |
| =safe_null=           | =optional<int*>=           | =src/main.cpp:135=          |
| =v=                   | =variant<string,int,double>= | =src/main.cpp:121=       |

** Emacs config for auto-deref

#+BEGIN_SRC emacs-lisp
;; Layout: source + stack + locals + breakpoints + IO.
;; Set before launching gdb; do not top-level (require 'gdb-mi).
(with-eval-after-load 'gdb-mi
  (setq gdb-many-windows t
        gdb-show-main t))

;; Tooltips show dereferenced values.
(with-eval-after-load 'gud
  (add-hook 'gdb-mode-hook #'gud-tooltip-mode))
#+END_SRC

** Usage: deref in GDB buffer

#+BEGIN_EXAMPLE
(gdb) p *res              # deref unique_ptr
(gdb) p *res2             # deref shared_ptr
(gdb) p *ref_count_       # deref shared_ptr target
(gdb) p safe_null         # inspect optional first; only deref if engaged
(gdb) p **safe_null       # only if safe_null holds non-null int*
(gdb) p std::get<0>(v)    # variant alternative by index
(gdb) p std::get<std::string>(v)  # variant alternative by type
#+END_EXAMPLE

* 4. Driving GDB (Built-in Abbreviations Only)

No custom keybindings. Type GDB's built-in abbreviations directly in the
console — any unambiguous prefix works, so single letters suffice. (Custom
single-key bindings were removed: they shadow =self-insert= in the console;
=C-c <letter>= bindings were removed: they added no value over typing.)

| Type | Command    | Notes           |
|------+------------+-----------------|
| =n=  | next       | Step over       |
| =s=  | step       | Step into       |
| =c=  | continue   | Resume          |
| =b=  | break      | Set breakpoint  |
| =f=  | finish     | Step out        |
| =r=  | run        | Restart program |
| =p=  | print      | Print value     |
| =bt= | backtrace  | Call stack      |
| =q=  | quit       | Quit debugger   |

Fallback: stock GUD keys =C-x C-a C-n/s/c/b/...= (from =gud-def=) always work.

* 5. Time-Travel Debugging

** Option A: GDB Record (built-in, zero-install)

Best-effort reverse stepping. =record full= fails on some syscalls, AVX,
and large I/O programs, and is slower on aarch64. If =record= errors, use
Option B or plain forward debugging.

#+BEGIN_EXAMPLE
(gdb) record                    # start recording
(gdb) rn  (reverse-next)        # step backward over
(gdb) rs  (reverse-step)        # step backward into
(gdb) rc  (reverse-continue)    # continue backward to breakpoint
(gdb) record stop               # stop recording
#+END_EXAMPLE

Type the abbreviations; no Elisp involved. Completions are disabled in GDB
buffers by =my/gdb-no-completions=, so typing stays clean.

** Option B: rr (recommended if available)

Full deterministic replay. Requires =rr= package. x86_64 only (no aarch64).

#+BEGIN_SRC sh
rr record ./build/<binary>   # record session (replace <binary>)
rr replay                    # replay with GDB
#+END_SRC

Then in Emacs: =M-x gdb RET gdb -i=mi rr replay= (adjust for your rr version).

* 6. Launch Workflow

One call from any project:

#+BEGIN_EXAMPLE
M-x my/cpp-debug RET <binary>   # builds Debug, launches gdb -i=mi with init flags
b / n / s / p                   # set bp, next, step, print (built-in abbreviations)
#+END_EXAMPLE

=my/cpp-debug= detects the project root, prompts for the binary (smart
default: newest executable under =build/=), rebuilds with
=cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug && cmake --build build=,
then launches =gdb -i=mi= with the §2 sets as =-ex= flags. No .gdbinit file,
no compile-command, no shortcuts needed. Root detection climbs to the
outermost =CMakeLists.txt= with a =project()= call, so invoking from a
subdirectory (e.g. =subproject/=) still builds the top-level project.

* 7. Complete init.el Block

Copy into =init.el= (=M-x my/cpp-debug= is the only entry point; no keys,
no .gdbinit file — §2 sets travel as =-ex= flags):

#+BEGIN_SRC emacs-lisp
;; --- GDB Built-in Setup (gud/gdb-mi) ---
(defconst my/gdb-init-args
  '("set print pretty on"
    "set print array on"
    "set print array-indexes on"
    "set print elements 0"
    "set print object on"
    "set print address off"
    "set pagination off"
    "set breakpoint pending on"
    "set confirm off"))

;; Layout (set before M-x gdb).
(with-eval-after-load 'gdb-mi
  (setq gdb-many-windows t
        gdb-show-main t))

;; Tooltips with deref.
(with-eval-after-load 'gud
  (add-hook 'gdb-mode-hook #'gud-tooltip-mode))

;; No completions in GDB buffers.
(defun my/gdb-no-completions ()
  (setq-local completion-at-point-functions
              (remq 'tempel-expand completion-at-point-functions))
  (setq-local corfu-auto nil)
  (when (bound-and-true-p corfu-mode)
    (corfu-mode -1)))

(with-eval-after-load 'gud
  (add-hook 'gdb-mode-hook #'my/gdb-no-completions))

;; One entry point: build (Debug) + launch GDB.
(defun my/cpp-debug-root ()
  (require 'project nil t)
  (let ((proj (and (fboundp 'project-current)
                   (condition-case nil (project-current) (error nil)))))
    (if (and proj (fboundp 'project-root))
        (project-root proj)
      default-directory)))

(defun my/cpp-debug-default-binary (root)
  (let ((dir (expand-file-name "build" root))
        best best-time)
    (when (file-directory-p dir)
      (dolist (f (directory-files-recursively
                  dir ".*$" nil
                  (lambda (d) (not (string-match-p "CMakeFiles\\|_deps" d)))))
        (when (and (file-regular-p f) (file-executable-p f)
                   (not (string-match-p "\\.\\(o\\|a\\|so\\|cmake\\|txt\\|mk\\)$" f)))
          (let ((mtime (file-attribute-modification-time (file-attributes f))))
            (when (or (null best-time) (time-less-p best-time mtime))
              (setq best f best-time mtime))))))
    best))

(defun my/cpp-debug (binary)
  (interactive
   (let ((root (my/cpp-debug-root)))
     (list (read-file-name "Debug binary: "
                           (expand-file-name "build" root)
                           (my/cpp-debug-default-binary root) t))))
  (let* ((root (my/cpp-debug-root))
         (binary (expand-file-name binary))
         (build-cmd (format "cmake -S %s -B %s/build -DCMAKE_BUILD_TYPE=Debug && cmake --build %s/build"
                            (shell-quote-argument root)
                            (shell-quote-argument root)
                            (shell-quote-argument root)))
         (flags (mapconcat (lambda (s) (concat "-ex " (shell-quote-argument s)))
                           my/gdb-init-args " "))
         (default-directory root))
    (unless (zerop (call-process-shell-command
                    build-cmd nil "*my-cpp-debug-build*" t))
      (pop-to-buffer "*my-cpp-debug-build*")
      (error "Debug build failed; fix errors before debugging"))
    (gdb (concat "gdb -i=mi " flags " --args " (shell-quote-argument binary)))))
#+END_SRC

* 8. Troubleshooting

| Issue                        | Fix                                      |
|------------------------------+------------------------------------------|
| No symbols                   | Rebuild with =-g -O0=, =-DCMAKE_BUILD_TYPE=Debug=; =rm -rf build= if cache is Release |
| Pretty-print missing         | Enable libstdc++ pretty-printers (e.g. =libstdc++6-*-dbg= / gdb python printers); check =info pretty-printer= |
| =record= slow / errors        | Expected on syscalls/AVX/large I/O; =record stop= and use forward debug or =rr= (x86_64 only) |
| Tooltip shows address        | =set print address off= (in =my/gdb-init-args=) |
| Completions pop up in console | =my/gdb-no-completions= disables them in GDB buffers |
| GDB prompt asks for command  | Use =M-x my/cpp-debug=; it builds the full =gdb -i=mi= command |
| Layout is single window      | =my/cpp-debug= sets layout before launch; plain =M-x gdb= needs =(setq gdb-many-windows t)= first |
