## Search & Navigation

| Key | Function | Description |
|-----|----------|-------------|
| `C-s` | `consult-line` | Fuzzy search in current buffer |
| `C-x b` | `consult-buffer` | Switch buffer (with preview) |
| `C-x r b` | `consult-bookmark` | Load bookmark |
| `M-s r` | `consult-ripgrep` | Fuzzy search in entire project |
| `M-y` | `consult-yank-pop` | Yank history (clipboard) |
| `C-r` | `consult-history` | Minibuffer history (after `M-x` etc.) |

**Fuzzy Search Example:**
1. Press `C-s`
2. Type: `def main` — filtered immediately
3. `C-n`/`C-p` for next/previous results
4. `RET` to jump

## Completion (Autocompletion)

| Key | Function | Description |
|-----|----------|-------------|
| `TAB` | corfu-complete | Accept current completion |
| `M-TAB` | corfu-next | Next option |
| `C-g` | corfu-quit | Cancel |

**Behavior:**
- Completion starts automatically after 1 character
- Appears inline under cursor (no popup window)
- Works in all modes

## Snippets (tempel)

| Key | Function | Description |
|-----|----------|-------------|
| `M-+` | `tempel-complete` | Expand snippet at point (completion) |
| `M-*` | `tempel-insert` | Insert snippet by name |

**Available Templates:**

| Template | Mode | Content |
|----------|------|---------|
| `if` | C/Python | If statement |
| `for` | C/Python | For loop |
| `def` | Python | Function definition |
| `main` | C/Python | Main entry point |
| `fun` | Bash | Function definition |
| `echo` | Bash | Echo statement |

**Example:**
1. Open new buffer (`C-x b`)
2. Type `def`
3. Press `M-+` (tempel-complete) or `M-*` (tempel-insert)
4. Template is inserted

## Build & Run

| Key | Function | Description |
|-----|----------|-------------|
| `C-c l r` | `my/run` | Run file (mode-dependent) |
| `C-c l b` | `my/cpp-build` | Build C++ project (CMake) |
| `C-c l c` | `compile` | Run arbitrary compile command |
| `C-c l k` | `kill-compilation` | Kill running compilation |
| `C-c l n` | `next-error` | Jump to next error |
| `C-c l p` | `previous-error` | Jump to previous error |
| `C-c C-c` | `python-shell-send-buffer` | Send Python buffer to shell |

### C++
1. `C-c l b` — Build project
2. `C-c l r` — Build + Run

### Python
1. `C-c C-c` — Send buffer to Python shell
2. `C-c l r` — Run script

### Bash
1. `C-c l r` — Run script

### Elisp
1. `C-c l r` — Evaluate current buffer
2. `C-x C-e` — Evaluate last S-expression

## Git (magit + diff-hl)

| Key | Function | Description |
|-----|----------|-------------|
| `M-x magit-status` | `magit-status` | Open git status |
| `C-x v =` | `diff-hl-diff-goto-hunk` | Show diff for current hunk |
| `C-x v n` | `diff-hl-next-hunk` | Jump to next changed hunk |
| `C-x v p` | `diff-hl-previous-hunk` | Jump to previous changed hunk |

**Diff-Hl:**
- Shows changes in fringe (left of line numbers)
- Green = line added, Red = deleted, Blue = modified
- Automatically active in prog-mode

**Magit Workflow:**
1. `M-x magit-status` — Open status buffer
2. `s` — Stage files
3. `c c` — Create commit
4. `P` — Push
5. `F` — Pull
6. `b b` — Switch branch

## Create Project

**`M-x my/project-new`** creates a new project:

1. Select language: `cpp` or `python`
2. Enter project name
3. Automatically:
   - Create directory structure
   - Create `.projectile` file
   - Create `CMakeLists.txt` (C++) or `main.py` (Python)
   - Create `.gitignore`
   - Initialize git repo + initial commit
   - Python: create virtual environment

**Location:** `~/Projects/<name>`
